# 컬러연구소 (`/lab/`)

시편 아카이브 서버에 붙은 세 번째 화면입니다. **개발 전에** 쓰는 도구:
배합을 정하기 전에 색을 예측하고, 목표색에 맞는 배합을 찾고, 찍어 본 뒤 얼마나 고칠지 계산합니다.

| 탭 | 하는 일 |
|---|---|
| 색 예측 | 도장 시편(바탕) 위에 1도·2도를 찍었을 때의 색. 바탕 / 1도 / 2도 단독 / 겹침 / 망점 평균(측색기 시야) |
| 배합 추천 | 목표 LAB에 가장 가까운 잉크 조합과 g (잉크 최대 4종). 2도를 고를 때는 1도 위에서 계산 |
| 보정 추천 | 지금 배합 + 찍어서 잰 LAB + 목표 → "YE +1.6g · RD +1.1g" (망점 패치에서 잰 값도 됨) |
| 과거 사례 | 시편 아카이브 배합의 LAB, 작업일지 시료의 `lab:`, 전사 시료 중 목표에 가까운 것 |
| 측색 라이브러리 | 잉크 · 도장 시편 · 동판 · 전사 시료 편집 / 저장 / JSON 내보내기·가져오기, **보정 프로필** |
| ΔE 계산기 | ΔE2000 · ΔE76 · ΔL/Δa/Δb/ΔC/ΔH와 "밝음 1.2 · 푸름 0.8" 같은 설명 |

위쪽 **SCI / SCE**로 어느 값끼리 계산할지 고릅니다. 라이브러리에 두 값이 다 있으면 언제든 바꿔 볼 수 있습니다.

## 측정 방법

측색기 기종을 몰라도 됩니다. **LAB만 있으면 동작**하고, 분광 반사율이 있으면 더 정확해집니다.

1. **잉크** — 먼저 **은폐 도막**(잉크를 꾸덕하게 발라 바탕이 안 비치게 한 것)을 잽니다. 흡수/산란 비율을 알려 줍니다.
   막 두께(얼마나 비치나)는 둘 중 하나로 정합니다.
   - ① **전사 시료 + 보정 프로필 (권장)** — 그 잉크로 찍은 망점 패치를 전사 시료에 쌓고 "보정 프로필"을 계산·적용합니다.
     **100% 동판이 없어도 됩니다** (95% 이하 망점 패치로 충분).
   - ② 얇게 찍은 값을 잉크 칸에 직접 — 흰·검정 카드 두 바탕 위, 또는 은폐 도막 + 한 바탕 위 (바탕값 포함).
     이때의 경화제 · 신나 %를 적습니다 (기본 20% · 30%).
   - 은폐 도막이 정말 안 비치는지는 흑백 차트 위에 발라 두 값이 같은지로 확인하세요.
   - 카드 바탕값은 "기본 카드값"에 한 번만 넣고 모든 잉크에 적용. 투명 잉크(CL 등)는 "투명"만 체크.
   - 이름을 `소광제`로 한 잉크가 있으면 소광제의 색 영향도 계산 (없으면 투명으로 봄)
2. **도장 시편(바탕)** — 컬러코드 · 도장처 · 표면마다 한 줄. 같은 코드라도 경면 / 패브릭엠보는 따로.
   여러 줄이면 화면과 작업일지에서 `D 2000@경면`, `C 1000@샘플도장 A`처럼 구분합니다 (작업일지 v3와 같은 규칙).
   흰 카드 · 검정 카드도 바탕으로 고를 수 있습니다 (기본 카드값).
3. **동판** — LPI · 부식 깊이(µm) · 설계 망점 %(1도 · 2도)를 적습니다.
   - 보정 프로필을 적용한 동판은 프로필의 **망점 곡선**(설계 망점 → 실효 덮임)과 막두께를 씁니다.
   - 나머지 동판은 입력값, 비우면 추정: 막두께는 **부식 깊이에 비례**, 퍼짐은 **같은 LPI 동판의 평균**.
4. **전사 시료** — 동판으로 네모 패치를 찍어 잰 값을 쌓아 둡니다: 날짜 · 동판 · 바탕 · 배합 g · 신나/경화제 % · 망점 % · 잰 값.
   - 잉크마다 **95 · 70 · 40 · 20%**처럼 망점을 넓게 찍을수록 프로필이 믿을 만해집니다. **SCI로 재는 것을 권장**합니다
     (광택이 다른 은폐 도막과 종이 시료를 SCE로 비교하면 오차가 커짐).
   - 저장하면 시료마다 지금 라이브러리로 예측한 색과 **오차(ΔE)**가 붙고, 동판별 평균 오차가 동판 표에 나옵니다.
   - 과거 사례 검색에도 나옵니다.
5. **분광(선택)** — 각 측정 칸의 "분광 붙여넣기"에 반사율을 붙입니다.
   400~700 nm 10 nm 간격 31개 / 360~740 nm 39개 / 380~780 nm 41개 / "파장 값" 두 열 모두 받고, % 값도 자동으로 0~1로 바꿉니다.
   **쓰는 잉크와 바탕이 모두 분광을 가지면** 자동으로 분광(31채널) 계산을 씁니다.

## 보정 프로필 (라이브러리 › 보정 프로필)

동판 하나를 골라 **[계산 (미리보기)]** → 결과를 보고 **[이 프로필 적용]**. 미리보기는 라이브러리를 바꾸지 않습니다.

- **1차 범위**: 동판 하나(그 동판이 막두께 기준 ×1.00), 1도, 고른 모드(SCI/SCE) 하나.
  은폐 도막만 있는 잉크는 **단독** 시료(투명 잉크·경화제·신나는 섞여도 됨)로 계산합니다.
  은폐 도막만 있는 잉크가 둘 이상 섞인 시료, 2도 시료, 다른 동판 시료는 이유와 함께 제외합니다.
  이미 얇게 찍은 값으로 보정된 잉크는 그 값을 그대로 쓰고(혼합 가능), 그런 잉크만 있으면 동판 막두께도 맞춥니다.
- **맞추는 것**: 잉크 1단위 산란(채널별), 망점별 실효 덮임(커지기만 하게), (필요하면) 막두께.
- **진단**:
  - 측정 — 화면 표시 문제(sRGB 밖) / 채널 범위 문제 / 표면 보정 문제(반사율이 정반사 가정보다 낮음)를 나눠서
  - 적합성 — 같은 막의 망점 패치들이 한 직선 위에 있는가, 은폐 도막과 바탕 사이의 막으로 설명되는가, 맞춘 뒤 오차가 큰가
  - 식별성 — 바탕 ≈ 은폐 도막, 막이 거의 은폐, 값이 탐색 범위 끝, 망점 한 단계뿐 · 범위 좁음
- **검증**: 시료를 하나씩 빼고 맞춘 뒤 빠진 시료를 예측한 ΔE00 (빠진 망점은 곡선에서 보간·외삽). 같은 시료로 잰 오차보다 정직합니다.
- **가정 민감도**: 가장 진한 패치의 실효 덮임을 데이터만으로 정할 수 없는 범위의 양 끝에서 95% 패치 예측이 얼마나 달라지나
  (통계적 신뢰구간이 아니라 가정에 따른 범위).
- **신뢰도**: 좋음 / 보통 / 낮음 / 부족. 부족이면 적용할 수 없고, 낮음이면 확인 표시 후 적용합니다.
- **적용 · 되돌리기**: 적용할 때 서버가 다시 계산해 미리보기와 입력이 같은지 확인합니다(바뀌었으면 거절).
  사용한 입력의 지문(스냅샷)을 함께 저장하고, 이후 시료·은폐 도막·바탕이 바뀌면 **"재맞추기 필요"**를 표시합니다 (자동 재계산은 하지 않음).
  바로 전 프로필로 되돌리거나 끌 수 있습니다. 원본 측정은 바뀌지 않습니다.
- **혼합 해석은 아직 실측 검증 전**입니다 (합성 데이터로만 확인).

## 계산 방식

- **Kubelka–Munk 2상수 모델**: 잉크마다 흡수(K)·산란(S)을 측정(또는 보정 프로필)에서 정하고,
  배합은 고형분 비율로 K·S를 더해 **바탕 위 유한 두께 막**의 반사율을 계산합니다 → 비침이 들어갑니다.
- 표면 반사는 Saunderson 보정 (SCI는 정반사 4% 포함, SCE는 제외).
- **신나는 증발** → 막 두께(고형분 비율)만 바꿉니다. **경화제는 투명 수지로 남아** 색을 묽게 합니다.
- 분광이 없으면 **3채널로 근사**합니다. 기본 기저는 **XYZ**(X/Xn, Y/Yn, Z/Zn) — 실제 반사율이면 언제나 0 이상이라
  진한 노랑·파랑도 잘리지 않습니다. 예전 방식(sRGB 기저)은 화면 색역 밖 색이 잘려서 오차가 커집니다 (계산 설정에서 선택).
- 보정 추천은 **모델이 지금 배합에서 틀린 만큼(측정 − 예측)을 그대로 옮겨** 계산하므로, 모델 오차가 있어도 방향이 맞습니다.
- 망점: 보정 프로필이 있으면 **망점별 실효 덮임 곡선**(잰 망점 사이 직선, 밖은 0%·100%까지 외삽).
  없으면 입력한 "50% 망점 → 실제 %"로 `1 − (1 − c)^γ` 곡선. 패치 색 = 바탕과 연속 전사막을 그 비율로 섞은 평균 (Yule–Nielsen n, 기본 1).
- 외부 라이브러리 없이 Python 표준 라이브러리만 씁니다.

## 저장 · 보안

- 저장 위치: `<dataRoot>/_lab/library.json` (저장할 때마다 이전 판을 `_backup/lab-library.<시각>.json`으로 보관)
- 두 곳에서 동시에 고치면 나중 저장이 막히고 "먼저 저장된 내용 불러오기"를 묻습니다.
- 아카이브와 같은 호스트 · Cloudflare Access · 교차 사이트(CSRF) 검사를 거칩니다.
- 시편 아카이브 JSON, 작업일지, rdp.db는 **읽기만** 합니다.

## 데모

```bash
python3 server.py --demo      # → http://localhost:8791/lab/
```

데모 라이브러리는 `colorlab/synth.py`가 만든 **합성 값**(실측 아님)입니다.
테스트도 이 합성 값으로 "진짜" 잉크값을 알고 있는 상태에서 엔진이 그 값을 되찾는지 확인합니다.
