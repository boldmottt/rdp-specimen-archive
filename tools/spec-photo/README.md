# 실물 크기 시편 사진 만들기

사진 한 장에서 **시편(또는 A4 용지) 네 귀퉁이**를 찍으면
① 원근(투시)을 펴고 ② 그 사각형의 실물 크기(mm)로 mm당 픽셀을 계산해
③ **원하는 실물 크기(기본 170×70mm)로 잘라** PNG/TIFF에 **DPI 메타데이터까지** 넣어 저장한다.
인디자인·일러스트에서 놓으면 그대로 170×70mm 로 들어간다.

## 실행

```bash
python3 tools/spec-photo/spec_photo.py          # http://localhost:8917 (브라우저 자동 열림)
python3 tools/spec-photo/spec_photo.py --port 9000 --no-browser
```

## 쓰는 순서

1. 사진을 끌어다 놓는다 (여러 장 가능)
2. 캔버스에서 **네 귀퉁이**를 끌어 맞춘다 — 기준이 되는 사각형(시편 외곽 또는 A4 용지)
   - `귀퉁이 자동 제안` 으로 대략 잡고 미세 조정해도 된다
   - 방향키 1px · Shift+방향키 10px · 돋보기로 정확히
3. **기준 사각형 실물 크기**를 입력한다 (A4 = 210×297, 시편 실측이면 그 값)
4. **뽑을 실물 크기** (기본 170×70mm) — 흰 점선이 실제로 잘릴 영역이다
5. `모든 사진 처리` → 결과에서 내려받기

한 장에서 귀퉁이를 찍었으면 **`이 귀퉁이를 전체에 적용`** 으로 나머지 사진에 그대로 쓸 수 있다
(카메라·삼각대 위치가 고정된 촬영이면 이 방식이 가장 빠르다).

## 원칙

- **업스케일하지 않는다** — 사진 해상도가 모자라면 경고만 하고 원본 픽셀을 지킨다.
  필요하면 `확대 허용` 을 켠다(흐려짐 감수).
- **자르기만 한다** — 원근 변환 1회 말고는 리샘플하지 않는다. 픽셀을 새로 만들지 않는다.
- **mm↔px 는 하나의 값** — 사진에서 잰 가로·세로를 각각 나누면 값이 조금씩 달라 결과 비율이
  실물과 어긋난다. 두 값을 평균한 하나의 px/mm 로 캔버스를 만들어 기준 사각형의 **실물 비율을 지킨다.**
  12% 넘게 어긋나면 경고한다(귀퉁이 오차 또는 광각 렌즈 왜곡).
- 결과물 이름: `시편_<번호>_<가로>x<세로>mm_<px>px.<확장자>`

## 구성

| 파일 | 역할 |
|---|---|
| `spec_photo_core.py` | 계산 핵심 — 원근 계수 · 워프 크기 · 자를 영역 · DPI 저장 (화면 없이 테스트 가능) |
| `spec_photo.py` | 로컬 서버 (표준 라이브러리 + Pillow) |
| `web/` | 화면 (캔버스 귀퉁이 편집) |

테스트: `python3 -m unittest tests.test_spec_photo -v` (저장소 루트에서)
