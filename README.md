# RDP 시편 아카이브 v2

패턴 시편을 쇼핑몰처럼 훑고, 컬러만 골라 A4 제안서로 뽑는 개인용 앱.

## 실행

1. `RDP Archive.command` 더블클릭 (또는 `python3 server.py`)
2. 브라우저가 `http://localhost:8791` 로 열림
3. 창을 닫으면 서버 종료. 다시 쓰려면 다시 더블클릭
   (로그인 자동 실행 `install_launchagent.sh`를 등록했다면 이 파일은 그 서버를 다시 시작하고 브라우저만 엽니다 — 창을 닫아도 계속 켜져 있음)

처음 한 번만: `python3 -m pip install --user pillow`

## 데이터 위치

```
~/Library/CloudStorage/GoogleDrive-<내 계정>/내 드라이브/RDP-Archive/
├── patterns/<패턴ID>.json     패턴 1건 = 파일 1개 (전부 여기에)
├── images/<패턴ID>/v01.jpg   170:70 → 2400×988
├── _orig/<패턴ID>/            업로드 원본
├── _backup/                   저장 전 자동 백업
├── _trash/                    삭제한 것 (복구 가능)
└── proposals/                 확정 제안서 스냅샷
```

드라이브 앱에서 이 폴더를 **"오프라인 사용 가능"** 으로 표시해두면 인터넷 없이도 이미지가 열립니다.

## 쓰는 순서

1. **새 시편** → 프로젝트/패턴 코드 입력 → 베리에이션 탭에서 컬러명·컬러코드·도장 입력
2. **이미지** 탭 → 이미지 추가 → 170:70 크롭(드래그·줌) → 저장
3. **배합** 탭 → 배합 추가/복제, 기준 배합 1개 체크
4. 목차에서 컬러 칩을 눌러 원하는 컬러를 고르고 체크 → **제안서 만들기**
5. 제안서에서 제목·고객·제안 포인트 입력 → **인쇄 / PDF**
   - A4 · 여백 없음 · **배율 100%** · **배경 그래픽 켜기**

## 규칙 몇 가지

- **컬러 베리에이션**: 라벨/작업정보/동판은 패턴 것이고, **컬러코드·도장·상태·날짜·배합·이미지**는 베리에이션 것입니다. 필드가 겹치지 않아 한쪽만 고치면 됩니다.
- **기준 배합**: 층(1도/2도)마다 1개. 두 개 이상이면 저장할 때 경고가 뜹니다.
- **이미지 비율**: 170:70 고정. 원본이 다른 비율이면 업로드할 때 잘라서 저장합니다.
- **삭제**: 실제로 지우지 않고 `_trash`로 옮깁니다. JSON에서 빠진 이미지는 저장할 때 자동으로 정리됩니다.
- **보관 기간(선택)**: `_backup`·`_trash`는 기본으로 계속 쌓입니다. `config.json`에 `"backupKeepDays": 180`, `"trashKeepDays": 90`처럼 넣으면 서버를 켤 때 그보다 오래된 것을 지웁니다.
- **확정 저장**: 제안서를 보낸 시점의 내용을 `proposals/`에 복사합니다. 나중에 배합을 고쳐도 보낸 제안서는 그대로입니다.

## 검색 문법 (목차)

검색창 한 칸에서 태그·프로젝트·동판·컬러·상태를 함께 거른다. 규칙은 `web/js/search.js` 한 곳에만 있다.

| 입력 | 뜻 |
|---|---|
| `G-51208` | 예전과 같은 전문 검색 (코드·이름·컬러·동판·태그·배합 동판) |
| `#컬러세미나` | 태그가 같은 시편 |
| `@"메탈 브라운"` 처럼 `#`·`@` 뒤 공백 | 따옴표로 감싼다 |
| `@MQ5` | 프로젝트 |
| `plate:26_015` | 동판 (작업 동판 · 도수별 동판 · 배합 동판) |
| `color:E3940` | 컬러 코드나 이름 |
| `status:가승인` | 그 상태인 컬러만 (카드 안에서도 걸린 컬러만 남는다) |
| `-` 접두 | 제외. 예) `#컬러세미나 -@MQ5` |

- 태그 칩 줄은 지금 프로젝트에서 많이 쓴 태그순이다. 누르면 검색창에 `#태그` 가 들어가고, 다시 누르면 빠진다.
- **담기(`N개 담기`)는 "걸린 컬러"만 담는다.** 예전에는 `color:` 로 한 컬러만 걸러도 그 패턴의 모든 컬러가 담겼다.
- 검색 상태는 `App.q` 하나뿐이라 저장 데이터(패턴 JSON)를 건드리지 않는다. 문법을 되돌리려면 `web/js/search.js` 를 지우고 `catalog.js` 의 `filtered()` 를 예전 모양으로 되돌리면 된다.
- 규칙 검사: `node --test tests/search.test.mjs` (CI에서도 돈다). `web/js/package.json` 의 `type: module` 은 이 테스트가 브라우저 없이 모듈을 읽기 위한 것이다.

## 선택 · 일괄 편집 · CSV

- 카드 오른쪽 위 **체크(✓)** 로 시편을 고른다. Shift = 범위, Cmd/Ctrl = 하나씩. (장바구니 담기와는 별개)
- 선택하면 툴바 아래에 **선택 바**가 뜬다 → `일괄 편집`.
- 일괄 편집 항목: 상태 · Rev · 작업자 · 양산 일정 · 태그 추가/제거.
  - 비운 칸은 **바꾸지 않는다**. 적용 전에 `N개 시편 · M칸` 미리보기가 나온다.
  - 컬러 범위: `검색에 맞는 컬러만` 또는 `모든 컬러`.
  - **동판은 일괄 편집에 없다.** 배합 줄과 어긋나면 DB 키(동판 포함)가 달라져 같은 배합이 두 줄로 남을 수 있어서, 동판은 상세 화면에서 하나씩 바꾼다.
  - 저장은 패턴당 PUT 1회, 순차. 실패한 시편만 선택에 남고 이유가 뜬다(먼저 저장된 경우 409).
- **CSV**: 지금 목록·검색에 걸린 컬러만 내려받는다. 엑셀용으로 UTF-8 BOM + CRLF, `=`,`+`,`-`,`@` 로 시작하는 값은 앞에 `'` 를 붙인다(수식 주입 방지).

## 색으로 찾기 · 컬러 보드

- 카드 오른쪽 아래 **◎** 를 누르면 그 컬러의 사진 대표색이 기준색이 되고, 정렬이 `색 가까운 순` 으로 바뀐다(ΔE2000).
- 색은 **사진에서 뽑은 값**이다(축소본 240px → 8색 양자화 → 상위 3색). 조명·무늬에 따라 측색값과 다르므로 참고용이다.
- `컬러 보드` 버튼 → `#/board/<프로젝트>`. 프로젝트의 컬러를 견본·코드·ΔE 로 한 장에 보여주고 인쇄할 수 있다(인쇄 규칙은 `body.board-mode` 로만 걸어 제안서 인쇄와 섞이지 않는다).

## 검증할 때 (중요)

- **실제 데이터를 가리키는 서버에 테스트용 요청을 보내지 않는다.** 2026-10-29 에 `_ui/state.json`(장바구니·제안서 설정)을 테스트 PUT 으로 덮어쓴 적이 있다.
- 브라우저 검증은 데모 인스턴스로: `./scripts/demo.sh 8910` → http://localhost:8910. `--demo` 는 sample-data 를 임시 폴더에 복사해 그 위에서만 돈다.
- 테스트는 `tests/test_server.py` 의 `TestSafety` 가 "모든 경로가 임시 폴더 안"인지 스스로 확인한다.
- 코드로 막을 수 없는 것: 손으로 `curl` 을 쏘는 일. 포트와 데이터 경로를 먼저 확인할 것(`/api/health` 가 `dataRoot` 를 돌려준다).

## 제안서 규격

- 표지 1장 + 패턴별 페이지
- 같은 패턴에서 컬러 2개 이상 → 한 페이지에 **170×70mm 실물 크기**로 세로 비교 (3개까지)
- 4개 이상이면 균등 분배해서 다음 장 (4→2+2, 5→3+2)
- 모든 페이지 하단에 "색상은 실물 시편 기준, 인쇄물은 참고용" 문구

## 문제가 생기면

- **서버에 연결할 수 없습니다** → `RDP Archive.command` 다시 실행
- **포트 사용 중** → 이미 떠 있는 서버가 있음. `http://localhost:8791` 접속
- **이미지가 안 보임** → 드라이브 동기화 상태 확인 (`_orig`는 있어도 `images`가 없으면 미동기화)
- **저장 실패** → 드로어 하단 메시지 확인. JSON 탭에서 문법 오류가 있으면 저장이 막힙니다.

## 컬러연구소

위쪽 **컬러연구소** 탭 → `/lab/`. 측색 라이브러리(잉크 · 도장 시편 · 동판)로 **바탕이 비치는 것까지 포함한 색 예측**,
목표색 배합 추천, 찍어 본 뒤 보정 추천, 과거 사례 검색, ΔE 계산을 합니다.
저장하는 것은 `<dataRoot>/_lab/library.json` 하나뿐이고, 시편·작업일지·rdp.db는 읽기만 합니다.
측정 방법과 계산 방식은 **[colorlab/README.md](colorlab/README.md)**.

## 외부 접속 (Cloudflare Tunnel + Access)

회사 PC에서도 열려면 → **[SETUP-TUNNEL.md](SETUP-TUNNEL.md)**

```bash
python3 check_tunnel.py                    # 준비 상태 점검
python3 setup_tunnel.py rdp.내도메인.com    # 터널 주소 등록
./install_launchagent.sh                   # (선택) 로그인 시 자동 시작
```

같은 네트워크(LAN)의 다른 기기에서 열려면 `RDP Archive (LAN).command`.
`config.json`에 `"lanPin": "4자리 이상"`을 넣으면 다른 기기는 처음 한 번 PIN을 입력해야 합니다(30일 유지, 5번 틀리면 1분 막힘).
넣지 않으면 같은 네트워크 누구나 읽고 고칠 수 있으니(배너에 '위험' 표시) PIN을 권장합니다. 이 맥에서의 접속과 터널은 PIN과 상관없습니다.

`config.json`의 `requireCfAccess`가 켜져 있으면 **Cloudflare Access를 통과한 요청(`Cf-Access-Jwt-Assertion`, 서명 검증 · `cfAccessTeamDomain` 필요)만** 허용합니다.
로컬(localhost) 접속은 그대로 됩니다.
