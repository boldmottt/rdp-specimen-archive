# RDP 시편 아카이브 v2

패턴 시편을 쇼핑몰처럼 훑고, 컬러만 골라 A4 제안서로 뽑는 개인용 앱.

## 실행

1. `RDP Archive.command` 더블클릭 (또는 `python3 server.py`)
2. 브라우저가 `http://localhost:8791` 로 열림
3. 창을 닫으면 서버 종료. 다시 쓰려면 다시 더블클릭

처음 한 번만: `python3 -m pip install --user pillow`

## 데이터 위치

```
~/Library/CloudStorage/GoogleDrive-loo4leesk@gmail.com/내 드라이브/RDP-Archive/
├── patterns/<패턴ID>.json     패턴 1건 = 파일 1개 (전부 여기에)
├── images/<패턴ID>/v01.jpg   170:70 → 2400×988
├── _orig/<패턴ID>/            업로드 원본
├── _backup/                   저장 전 자동 백업
├── _trash/                    삭제한 것 (복구 가능)
└── proposals/                 확정 제안서 스냅샷
```

드라이브 앱에서 이 폴더를 **"오프라인 사용 가능"** 으로 표시해두면 인터넷 없이도 이미지가 열립니다.

## 쓰는 순서

1. **새 시편** → 프로젝트/패턴 코드 입력 → 베리에이션 탭에서 컬러명·컬러코드·도장 입력
2. **이미지** 탭 → 이미지 추가 → 170:70 크롭(드래그·줌) → 저장
3. **배합** 탭 → 배합 추가/복제, 기준 배합 1개 체크
4. 목차에서 컬러 칩을 눌러 원하는 컬러를 고르고 체크 → **제안서 만들기**
5. 제안서에서 제목·고객·제안 포인트 입력 → **인쇄 / PDF**
   - A4 · 여백 없음 · **배율 100%** · **배경 그래픽 켜기**

## 규칙 몇 가지

- **컬러 베리에이션**: 라벨/작업정보/동판은 패턴 것이고, **컬러코드·도장·상태·날짜·배합·이미지**는 베리에이션 것입니다. 필드가 겹치지 않아 한쪽만 고치면 됩니다.
- **기준 배합**: 층(1도/2도)마다 1개. 두 개 이상이면 저장할 때 경고가 뜹니다.
- **이미지 비율**: 170:70 고정. 원본이 다른 비율이면 업로드할 때 잘라서 저장합니다.
- **삭제**: 실제로 지우지 않고 `_trash`로 옮깁니다. JSON에서 빠진 이미지는 저장할 때 자동으로 정리됩니다.
- **확정 저장**: 제안서를 보낸 시점의 내용을 `proposals/`에 복사합니다. 나중에 배합을 고쳐도 보낸 제안서는 그대로입니다.

## 제안서 규격

- 표지 1장 + 패턴별 페이지
- 같은 패턴에서 컬러 2개 이상 → 한 페이지에 **170×70mm 실물 크기**로 세로 비교 (3개까지)
- 4개 이상이면 균등 분배해서 다음 장 (4→2+2, 5→3+2)
- 모든 페이지 하단에 "색상은 실물 시편 기준, 인쇄물은 참고용" 문구

## 문제가 생기면

- **서버에 연결할 수 없습니다** → `RDP Archive.command` 다시 실행
- **포트 사용 중** → 이미 떠 있는 서버가 있음. `http://localhost:8791` 접속
- **이미지가 안 보임** → 드라이브 동기화 상태 확인 (`_orig`는 있어도 `images`가 없으면 미동기화)
- **저장 실패** → 드로어 하단 메시지 확인. JSON 탭에서 문법 오류가 있으면 저장이 막힙니다.

## 작업일지 (PCCS3)

위쪽 **작업일지** 버튼 → `/pccs/`. 작업일지 폴더의 v3 일지를 자동 검사하고, 동판별 타임라인을 보여 줍니다 (읽기 전용).
설정(`worklogDir`)과 PyYAML 설치는 **[pccs/README.md](pccs/README.md)**.

## 외부 접속 (Cloudflare Tunnel + Access)

회사 PC에서도 열려면 → **[SETUP-TUNNEL.md](SETUP-TUNNEL.md)**

```bash
python3 check_tunnel.py                    # 준비 상태 점검
python3 setup_tunnel.py rdp.내도메인.com    # 터널 주소 등록
./install_launchagent.sh                   # (선택) 로그인 시 자동 시작
```

`config.json`의 `requireCfAccess`가 켜져 있으면 **Cloudflare Access를 통과한 요청(`Cf-Access-Jwt-Assertion`, 서명 검증 · `cfAccessTeamDomain` 필요)만** 허용합니다.
로컬(localhost) 접속은 그대로 됩니다.
